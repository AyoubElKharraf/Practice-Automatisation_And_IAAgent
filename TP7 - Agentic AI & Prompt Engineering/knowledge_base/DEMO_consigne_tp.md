# DOCUMENT FICTIF — Consigne de TP (fixture de test)

Statut : exemple inventé, non officiel. Créé pour tester les citations.

## Livrable de démonstration

Un rapport de test doit décrire le résultat attendu, le résultat obtenu et un statut pour chaque cas. Une réponse fondée sur les documents doit indiquer le document et le passage utilisé.

## Cas de démonstration

Inclure une question documentée, une question sans réponse dans les documents et une demande contenant plusieurs intentions.
